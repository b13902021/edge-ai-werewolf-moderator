---

### 👁️ `ai_moderator.py` (底層視覺與語音引擎)
- **多目標視覺辨識**：支援最高 10 人同時入鏡。採用指骨向量內積演算法，無視鏡頭傾斜與翻轉。精準辨識 1~9 (華人常規手勢)、10 (拳頭)、11 (食指朝下)、12 (二指朝下)，以及「讚」(0) 與「倒讚」(-1)。
- **防閃爍捕捉 (`read_gesture`)**：自動追蹤畫面手勢，需穩定維持 3 秒並包含 0.5 秒容錯緩衝 (Debounce) 防掉幀。支援黑色小字體中文提示 UI (`prompt`)。
- **防洩密 UI (`show_message`)**：使用 `tkinter` 彈出無邊框、強制置頂的機密視窗（如顯示查驗身分、被刀號碼），3 秒後自動銷毀，**絕不會在 Terminal 留下紀錄**。
- **真人語音播報 (`speak`)**：調用微軟 Edge 神經網路繁體中文語音庫，具備阻塞式同步播放機制，確保法官台詞播報完畢後才推進遊戲流程。

## 🚀 目前已完成進度 (10 人局標準版)

- [x] **Day 1 報到機制**：首夜支援狼人、女巫、預言家、獵人對鏡頭比數字完成身分綁定。
- [x] **狼人階段**：支援三狼共同睜眼，並以單手勢完成刀人確認，支援倒讚 (-1) 空刀。
- [x] **女巫階段**：完整讀取昨夜死者，支援比讚 (0) 救人，或比號碼毒人，嚴格控管單局解藥與毒藥狀態 (`antitode`, `poison`)。
- [x] **預言家階段**：支援查驗號碼，系統利用 `show_message` 無痕回報所查驗的陣營。
- [x] **獵人階段**：判定是否吃毒，顯示出局能否開槍 (`gun`)，並支援白天出局的連動開槍 (`shooting()`)。
- [x] **神職隱身衣機制**：神職死亡時，法官仍會唸出台詞並執行 `time.sleep(15)` 假等待，防止活人猜出神職生死。
- [x] **白天結算與投票**：整合死者廣播、勝利判定；投票採 Terminal 手動輸入以防止白天光源或動作干擾誤判。
